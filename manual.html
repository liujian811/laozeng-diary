销售Agent系统使用手册

三大Agent协同工作，助力销售业务智能化

📋 系统概览

三大Agent协同工作

  • 📊 销售数据官 - 自动化销售数据分析、日报生成
  • 🎯 销售军师 - 基于客户画像生成销售策略和话术
  • 🔔 销售督导官 - 客户跟进提醒、任务督办

📊 一、销售数据官

功能说明

自动生成销售日报，追踪业绩数据，推送到飞书。

使用方式

方式1：自动运行（推荐）

  • 每天18:00自动生成日报
  • 自动推送到飞书群
  • 无需人工操作

方式2：手动生成

# 进入目录
cd /root/.openclaw/workspace/sub-agents/sales-data-agent

# 运行Agent生成日报
python3 agent.py

日报内容

  • 今日核心数据（线索、沟通、拜访、签约）
  • 本周累计业绩
  • 重点客户跟进情况
  • 明日计划

配置说明

编辑 sub-agents/sales-data-agent/config.yaml：

feishu:
  webhook_url: ""  # 填写飞书群Webhook地址

data_sources:
  - type: manual      # 当前使用手动录入
  - type: youzan_api  # 可选：接入有赞CRM

🎯 二、销售军师

功能说明

输入客户7字段信息，自动生成完整销售策略。

输入格式（7字段）

{
  "industry": "行业",           // 例如：药店、烘焙
  "scale": "规模",              // 例如：连锁10家、单店
  "channels": "获客渠道",       // 例如：美团、线下
  "problems": "业务痛点",       // 例如：获客成本高
  "has_private_domain": false,  // 是否已有私域
  "concerns": "客户顾虑",       // 例如：担心效果
  "current_stage": "D类"        // D类/L类/C类
}

使用示例

# 进入目录
cd /root/.openclaw/workspace/sub-agents/sales-strategy-agent

# 编辑客户信息
vim customer_input.json

# 运行Agent生成策略
python3 agent.py customer_input.json

输出内容（11模块）

  1. 客户画像分析
  2. 分层标准判定
  3. 需求优先级排序
  4. 方案配置建议
  5. 产品组合策略
  6. 话术策略
  7. 推进路线图
  8. 竞品对比话术
  9. 首次接触话术
  10. 异议处理话术
  11. 阶段性里程碑规划

🔔 三、销售督导官

功能说明

自动提醒跟进客户，督办任务，把控销售节奏。

使用方式

方式1：自动提醒（推荐）

  • 09:00 晨间提醒 - 今日待办+逾期预警
  • 17:00 晚间总结 - 完成情况+明日重点
  • 自动推送到飞书

方式2：手动检查

# 进入目录
cd /root/.openclaw/workspace/sub-agents/operation-agent

# 检查逾期客户
python3 agent.py --check-overdue

跟进规则

新线索：24h → 3天 → 7天
意向客户：2天跟进周期，最多逾期3天
谈判客户：1天跟进周期，最多逾期1天
待签约：12小时跟进，不能逾期

⏰ 定时任务时间表

时间 Agent 任务
09:00 销售督导官 晨间提醒
12:00 AI情报系统 情报更新（午）
17:00 销售督导官 晚间总结
18:00 销售数据官 日报生成
20:00 AI情报系统 情报更新（晚）

🚀 快速开始

配置飞书Webhook（必须）

在飞书群中添加"自定义机器人"，复制Webhook地址，编辑三个Agent的config.yaml文件填写。

测试Agent

进入各Agent目录，运行 python3 agent.py 测试功能是否正常。

等待自动运行

定时任务已设置，明天09:00开始自动运行，无需人工干预。

⚠️ 注意事项

  • 飞书Webhook必须配置 - 否则无法接收提醒和日报
  • 数据目前是模拟数据 - 需要接入有赞CRM或飞书表格获取真实数据
  • 销售军师需要输入客户信息 - 目前为交互式输入，后续可改为API调用
  • 定时任务已自动运行 - 明天09:00开始第一次提醒
