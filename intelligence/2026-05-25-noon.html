🚀 OpenClaw v2026.5.24-beta.1：性能+可靠性+安全三重升级

来源：GitHub Releases / releasebot.io · 2026-05-24 | 查看发布页

OpenClaw于5月24日发布v2026.5.24-beta.1版本，聚焦生产环境的可靠性提升与安全加固：

  • Android Talk Mode：切换到实时Gateway中继语音会话，支持流式麦克风输入、实时音频播放、工具结果桥接和屏幕转录——语音交互体验大幅提升
  • QA-Lab：新增Codex-vs-Pi runtime parity测试层、runtime工具覆盖率报告、个人Agent审批拒绝场景测试，以及仅报告不修改MEMORY.md的 dreaming shadow-trial 场景
  • Gateway/性能：新增pnpm test:restart:gateway基准测试工具，用于测量重复重启就绪时间、停机时间、追踪和资源斜率
  • Gateway/配置：暴露配置查找重载元数据，工具可在应用配置编辑前区分"需重启"、"热重载"和"无操作"字段
  • Telegram：新增白名单原生DM草稿预览功能，临时工具进度可在草稿中展示，最终答案走持久交付路径
  • CLI：拒绝超过65535的显式端口号，防止绑定失败
  • Codex app-server：保留插件工具auth profiles，使OpenClaw动态工具能正确解析provider凭证
  • Memory/search：JS fallback vector path改为bounded rowid批次扫描，并在批次间让出事件循环，避免大表扫描时阻塞Node.js主线程数秒
  • Telegram：论坛话题消息路由改进，防止单个话题阻塞同级话题流量
  • Twitch：使用Twurple聊天意图注册刷新token，保持聊天访问可用
  • Agents/subagents：collect-mode announce队列批处理改进，兼容同路由消息的聚合
  • Skills：监听技能根目录变化时自动刷新现有会话技能快照，无需重启会话
