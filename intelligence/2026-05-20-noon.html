🚀 OpenClaw v2026.5.19-beta.1：Browser安全 + 工具插件 + 调试技能三箭齐发

2026年5月19日，OpenClaw发布v2026.5.19-beta.1版本，聚焦Browser安全加固、开发者工具链扩展和Codex生态优化：

  • Browser安全增强：快照中显示待处理和最近处理的弹窗对话框，当动作打开弹窗时返回blockedByDialog状态，支持通过browser 对话框 --对话框-id应答弹窗（#83447）
  • Browser CLI增强：新增openclaw browser evaluate --超时-ms，支持长运行页面函数扩展超时预算（#83447）
  • Codex应用服务器改进：按运行时界面限定OpenClaw提示词引导范围，原生Codex保留自有基础/个性指令，OpenClaw仅贡献运行时上下文、交付指导和显式范围命令提示（#83454）
  • Docker/Podman：新增OPENCLAW_IMAGE_PIP_PACKAGES支持本地镜像构建时可选Python包安装；新增OPENCLAW_IMAGE_APT_PACKAGES运行时中性镜像构建参数（#83771，#62431）
来源：OpenClaw Release Notes / GitHub

🔧 开发者工具链革命：defineToolPlugin + Python调试 + MemeMaker

  • Obsidian技能更新：目标指向官方obsidian CLI并要求其注册二进制文件，替代第三方obsidian-cli
