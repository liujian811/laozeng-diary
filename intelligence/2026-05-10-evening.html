🦞 OpenClaw最新动态

OpenClaw五月大更新：从开源玩具到企业就绪平台的质变

来源：ReleaseBot / OpenClaw Release Notes May 2026 · 2026-05-10

OpenClaw在五月第二周集中释放了一系列重大更新，覆盖语音、内存、性能、安全、多平台等核心维度：

  • Google Meet语音桥接持久化：会议退出后会话仍然存活。Stateful CLI session commands现在通过gateway-owned runtime路由，joined realtime sessions在启动CLI进程退出后依然存活。这意味着销售团队可以启动AI语音会议助理后关闭终端，Agent继续运行
  • Feishu语音媒体处理：新增重复文本抑制（防止TTS重复播放相同内容）+ 回退链接处理。对于使用飞书作为企业IM的销售团队，语音消息体验大幅提升
  • TTS插件即时激活：TTS插件现在支持热加载，无需重启Gateway即可激活。这意味着销售团队可以随时切换语音合成提供商而中断服务
  • 内存向量存储分离：builtin sqlite-vec store readiness与embedding-provider readiness分离，local vector-store失败不再看起来像provider failure，provider failure也不再掩盖健康的local vector store。企业部署时诊断更精准
  • Gateway性能缓存：lazy-load early runtime discovery、defer maintenance timers until after readiness、trim duplicate plugin auto-enable work。大型部署启动不卡顿
  • Discord/Telegram/Slack全渠道改进：Discord native commands支持CJK/多行命令文本、status reactions支持thinking/done生命周期、slash-command registration优化。Telegram支持stale reply suppression、gramMY polling优化。Slack支持Socket Mode pong-timeout重连折叠
  • Cron修复链：修复lazy cron startup在hot-reload race中丢失的问题，abort-drain embedded runs after extended no-progress stall，merge session id/key aliases in diagnostic tracking。自动化任务可靠性全面提升
  • CLI插件加固：reject unowned command roots before managed proxy startup、honor tools.alsoAllow as optional plugin tool discovery hint、cold-load selected plugin tool registries when partial coverage。插件系统更健壮
  • Doctor --fix增强：即使验证失败（如缺少插件）也会提交safe legacy migrations，agents.defaults.llm等legacy keys始终被清理。升级更平滑
  • Anthropic thinking profiles暴露：Claude Opus 4.7的adaptive、xhigh、max thinking level从bundled provider-policy artifact暴露，非runtime caller不再降级到high
💡 销售业务价值：这批更新标志着OpenClaw正式进入"企业就绪"状态。Google Meet语音持久化=销售团队可以部署7×24语音会议助理。Feishu语音改进=中国市场企业客户的IM集成体验达标。内存分离+性能缓存=大型销售组织（100+Agent）部署时不卡顿。Cron修复链=自动化销售流程（定时报表、线索提醒、跟进任务）不再静默失败。Telegram/Discord改进=海外客户触达更可靠。Doctor增强=IT部门升级时不头疼。综合来看，OpenClaw已经具备了向"千人规模销售团队"提案的基础设施条件。

OpenClaw Plugin生态进化：外部化、商店化、安全化三轨并行

来源：ReleaseBot / OpenClaw Plugin Updates · 2026-05-10

OpenClaw的插件系统正在经历从"内置捆绑"到"外部商店"的战略转型：

  • ClawHub商店优先：ClawHub-backed diagnostics with npm fallback，storepack-first channel plugins保持remote source而不是变成npm-only。插件商店成为首选安装源
  • 发布验证加强：reject TypeScript-only packages without compiled dist/*.js output、verify published npm tarballs expose compiled runtime entries。杜绝"源码包"陷阱
  • Beta通道智能切换：beta-installed OpenClaw package updates保持在beta plugin channel，即使config仍说stable。Discord等externalized plugins从compiled @beta packages更新
  • 安全加固：report configured plugins that are present but blocked by path-safety checks as blocked instead of stale。路径安全检查更透明
  • OpenRouter DeepSeek V4：advertise DeepSeek V4 thinking levels including xhigh and max，/think validation不再拒绝OpenRouter-routed DeepSeek V4 models
💡 销售业务价值：插件商店化=企业客户可以像安装App一样安装AI能力扩展，无需技术团队介入。发布验证=杜绝"安装后不能用"的糟糕体验。Beta通道=尝鲜客户可以提前使用新功能。OpenRouter DeepSeek V4=成本敏感客户可以用更低价格的模型获得thinking能力。对销售团队而言，这意味着可以向客户承诺"你的AI能力可以像手机App一样不断扩展"，而不是"这是一套封闭系统"。
