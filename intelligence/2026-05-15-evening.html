OpenClaw Plugin SDK重构与架构升级：为插件生态定规矩

来源：ReleaseBot · 2026-05-09/15

OpenClaw在5月第二周进行了一系列重要的Plugin SDK架构调整，标志着插件生态从"野蛮生长"进入"规范化治理"阶段：

  • 废弃公共子路径：废弃目前仅被一两个捆绑插件使用的公共子路径，同时保持其可导入性，引导新插件代码转向专注的共享SDK seams或插件自有API
  • 移除provider-specific辅助函数：从公共导出中移除provider-specific的model、stream和xAI兼容辅助函数，将捆绑调用者移至provider-owned模块
  • 暴露运行时模型元数据：向原生插件工具工厂暴露运行时提供的活跃模型元数据，用于诊断和插件自有策略决策（Fixes #77857）
  • Codex原生代码模式：启用Codex原生code-mode-only用于harness线程，延迟的OpenClaw动态工具通过Codex自己的可搜索代码执行面运行，而非PI式包装器
  • 网关技能上传：新增opt-in私有技能存档上传安装路径，由skills.install.allowUploadedArchives控制，仅当操作员显式启用时代码安装面可用（#74430）
💡 销售业务价值：Plugin SDK重构是"平台成熟"的关键信号：①API稳定性承诺：废弃公共子路径意味着OpenClaw敢于对历史包袱说不，新插件开发者获得更清晰的API边界。②安全即架构：将provider-specific功能移回provider-owned模块，减少了"意外权限"的表面积——每个provider只能访问自己需要的东西。③诊断可见性：暴露运行时模型元数据让插件能根据当前模型做出智能决策（例如"如果是Gemini模型，使用不同的prompt策略"）。④技能分发新路径：允许上传zip-backed skills意味着企业内部可以私有分发自定义技能，不必发布到公共npm——这对金融、医疗等合规行业至关重要。

Discord语音系统升级：实时诊断、Talk指令、解码器优化

来源：OpenClaw Updates · 2026-05-09/15

OpenClaw Discord语音能力迎来多项实质性升级，从"能用"迈向"好用"：

  • 实时语音诊断：新增speaker turns、playback resets、barge-in detection和audio cutoff analysis实时诊断，运维人员可以精确排查语音质量问题
  • Talk实时指令：新增talk.realtime.instructions，操作员可追加实时语音风格指令，同时保留OpenClaw内置的agent-consult指导（#79081）
  • opusscript解码器：测试和源码安装默认使用纯JS opusscript解码器，忽略可选原生@discordjs/opus构建，避免非语音性能通道的慢速原生插件编译
  • 原生opus opt-in：为实时语音性能通道添加opt-in原生@discordjs/opus安装脚本和解码器偏好
  • 语音交互修复：修复late realtime consult tool calls不窃取speaker context、forced-consult transcript片段跳过、back-to-back语音答案排队不切断等问题
💡 销售业务价值：Discord语音升级打开了"AI语音客服"场景：①实时诊断=可运维：企业部署AI语音助手最怕"有时候好用有时候不好用"，实时诊断让问题可定位、可修复。②Talk指令=品牌一致性："用友好专业的语气回答"——操作员可以实时调整AI语音风格，确保符合品牌调性。③纯JS默认=降低门槛：不再需要编译原生插件，Docker部署更简单。④语音竞争：当竞品还在做文字客服时，OpenClaw已经支持带实时诊断的语音交互——这是差异化卖点。

Claude Code v2.1.136发布：企业级功能全面升级

来源：ReleaseBot · 2026-05-15

Anthropic发布Claude Code v2.1.128-136系列更新，聚焦企业部署、安全控制和开发者体验：

  • 插件系统扩展：--plugin-dir现在接受.zip存档，新增--plugin-url从URL获取插件存档，支持试用后再上架市场
  • 跨项目历史搜索：Ctrl+R反向搜索默认覆盖所有项目的所有prompts，按Ctrl+S缩小到当前项目或会话
  • 自动模式硬拒绝：新增settings.autoMode.hard_deny规则，无条件阻止匹配操作，即使更广泛的allow规则适用
  • Hooks增强：hooks现在接收活跃effort level（通过effort.level JSON字段和$CLAUDE_EFFORT环境变量）
  • OAuth可靠性修复：修复并行会话refresh-token竞争导致的401死锁、MCP OAuth并发刷新丢失token、并发credential write导致的罕见登录循环
  • 子Agent缓存优化：子agent进度摘要现在命中prompt cache，cache_creation token成本降低约3倍
💡 销售业务价值：Claude Code企业级升级是"AI编程进入主流企业"的信号：①插件URL=内部分发：企业可以从内部artifact store分发插件，不必公开到市场——解决合规顾虑。②hard_deny=安全底线："即使允许自动模式，某些操作（如删除生产数据库）永远不允许自动执行"——这是CISO会喜欢的功能。③OAuth修复=企业SSO就绪：并发token刷新修复意味着企业SSO集成更可靠。④3倍缓存成本降低：对于大规模使用Claude Code的企业，这意味着显著的API成本节省。
