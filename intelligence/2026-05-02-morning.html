OpenClaw v2026.4.29「日常运营」持续深化——从"酷炫演示"到"凌晨2点可托付"

来源：GitHub Releases / 社区深度解读 · 2026-04-29

v2026.4.29 的发布标志着 OpenClaw 正在完成从「酷炫演示平台」到「可托付、可审计、可监督的生产基础设施」的关键转型。这一版本的核心信号是：安全不再是可选项，而是默认关闭（Fail-Closed）。

  • 消息队列智能排空（steer模式）：Pi steering 消息在下一个 model boundary 批量排空，500ms debounce 防止消息洪泛。对于销售场景中的高频客户咨询，这意味着 Agent 不会因为消息堆积而「发疯」。
  • Memory 进化为「人脉感知操作系统」：新增 people wiki 元数据、relationship graphs、per-conversation allow/deny 过滤器。销售团队终于可以在 Agent 中维护客户人脉网络，而不担心隐私泄露。
  • NVIDIA 正式加入 Provider 目录：API-key onboarding、静态目录元数据支持，NVIDIA 托管模型可直接通过 provider prefix 调用——为需要 GPU 加速的本地部署销售 Agent 打开了大门。
  • 安全收紧（Fail-Closed）：已配置的 tools.exec / tools.fs 不再隐式拓宽受限 profile，需要显式 alsoAllow。这是对金融、医疗等合规销售场景的强力支持。
  • 自动承诺推断（Inferred Commitments）：opt-in 隐藏批量提取、per-agent/per-channel 作用域、heartbeat 交付——Agent 可以主动提醒销售跟进承诺事项，无需人工设置提醒。
  • Codex Computer Use 支持：新增 /codex computer-use status/install，支持 Computer Use 的自动安装和 MCP server 检查，AI 销售 Agent 现在可以真正「操作电脑」完成报价单生成。

💡 对销售业务的价值

  • Fail-Closed 安全模式消除 IT 合规审批障碍，金融/医疗/保险销售终于可以大规模部署 AI Agent
  • 人脉感知 Memory让 Agent 记住「张总是李总介绍来的」这类关键关系，自动触发转介绍激励流程
  • 自动承诺推断解决销售最头疼的「我答应客户什么但忘了」问题——Agent 主动在 heartbeat 中提醒
