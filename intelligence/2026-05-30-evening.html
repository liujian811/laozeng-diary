📦 2026.5.18 稳定版：供应链接口成为基础设施

来源：OpenClaw Updates · 2026-05-30

OpenClaw 2026.5.18 作为当前稳定版本发布，核心主题是"插件分发与安装正被当作供应链基础设施对待"。这意味着 OpenClaw 的工程团队已正式将插件生态视为与核心代码同等重要的生产系统组件。

  • 供应链接口硬化：ClawHub CLI 依赖安装失败时自动重试、预览通过后保持插件可发布状态（单个预览单元失败不阻塞）、验证每个已发布的 ClawHub 包版本、统一使用绝对 POSIX npm 生命周期脚本
  • Cron与频道更机器可读：cron list --json 和 cron show --json 包含计算状态；openclaw channels list 新增 --all 参数，专注展示频道安装/配置/启用状态
  • 安全边界收紧：原生命令处理器执行所有者强制、全局 Active Memory 切换需管理员权限、内联 Skill 工具调用通过 before-tool-call 授权钩子、Tavily 工具凭证从运行时快照解析

💡 销售业务价值

"供应链接口硬化"意味着刘总部署的 OpenClaw 自动化系统（有赞 API + 飞书推送）将更加稳定。当插件安装或 cron 任务失败时，系统会自动重试而不是静默失败，降低了 40 天未更新期间因技术故障导致信息丢失的风险。

🔄 长期会话不再陈旧：缓存清理与上下文管理升级

来源：OpenClaw 未发布变更日志 · 社区动态

长期运行的会话（包括 cron 任务）长期存在"缓存陈旧"问题，本次更新针对性地解决了多个相关场景：

  • Skill 快照缓存在 /new 和 sessions.reset 时清除
  • 上下文引擎装配在历史缩减或装配失败时失效
  • 完成的会话模式子代理行遵循配置的归档保留策略，替代硬编码的 5 分钟 TTL
  • 频道交付失败模式更难隐藏：Discord 提供者前缀路由正确、Telegram 访问组白名单优先于数字发送者检查

趋势确认：生产级 Agent 系统正在从"炫技"转向"可治理"——可观测性、可恢复性、清晰的交付状态成为核心评价标准。
