🛡️ OpenClaw六月演进：从"可信运营"到" operator-grade trust"

来源：OpenClaw Release Notes｜2026-06-01/02

继v2026.6.1发布后，OpenClaw社区持续聚焦" boring reliability"——将Agent从Demo级玩具推向可7x24运行的生产级系统。六月开局的核心不是 flashy features，而是 invisible plumbing：

  • Active Memory timeout保护：Memory recall慢、Discord socket stall、插件禁用等场景下，Agent可优雅降级而非崩溃
  • 浏览器实时传输契约：Generic browser realtime transport + Google Live browser Talk sessions + Gateway relay，Agent成为实时协作者而非偶尔调用工具的聊天框
  • 本地模型embedding精细化：Ollama-backed memory search支持nomic-embed-text、qwen3-embedding、mxbai-embed-large模型专属query前缀
  • 插件边界显性化：Provider model catalogs、endpoint host metadata、OpenAI-compatible request hints全部从隐藏core table移至显式配置
  • 安全fail-closed持续硬化：Slack交互事件严格owner allowlist、附件路径解析fail closed、危险security-audit flags禁止通过gateway config工具启用、ReDoS-prone markdown parser替换
  • 生产级会话连续性：Codex会话绑定、compaction交接、媒体交付重试均可恢复；iMessage监控状态SQLite化

"2026年的赢家不是承诺无限自主的系统，而是当memory recall变慢、Discord socket stall、插件被禁用时，依然保持工作的系统。" —— 开源社区共识
