⭐ OpenClaw突破20万+ GitHub Stars，开源基金会治理确立

截至2026年2月，OpenClaw GitHub Stars已突破20万，从2025年11月的"Clawd"周末项目成长为史上增长最快的开源AI项目之一。创始人Peter Steinberger于2026年2月14日宣布加入OpenAI，项目正式移交独立开源基金会治理，确保社区持续性和MIT许可证下的完全开放性。

项目历程：Clawd（2025.11）→ Moltbot（2025.12，Anthropic商标通知后改名）→ OpenClaw（2026.1.30，最终品牌）。三次改名一次加密骗局（$16M假$CLAWD代币），折射出 viral open-source 项目的典型治理挑战。

🛡️ 安全治理全面升级：VirusTotal合作+恶意技能扫描

信息窃取器首次定向攻击AI Agent配置：2026年2月，Hudson Rock披露Vidar变种窃取OpenClaw用户配置文件——包括 openclaw.json（网关令牌）、device.json（加密密钥）和 soul.md（Agent核心行为准则）。这标志着恶意软件从"偷浏览器密码"进化为"偷AI灵魂"。

主动防御：OpenClaw官方与VirusTotal建立合作，对ClawHub上传技能进行恶意代码扫描；发布威胁模型；增加潜在配置错误审计能力。同时修复CVE-2026-21636等漏洞，所有早于v2026.1.29版本均需立即升级。

#安全事件 #VirusTotal #ClawHub安全 #信息窃取器 #CVE-2026-21636

⚠️ 暴露实例危机：数十万未认证节点面临RCE风险

SecurityScorecard STRIKE团队发现数十万暴露的OpenClaw实例，攻击者可通过远程代码执行（RCE）利用这些节点。由于OpenClaw通常绑定邮件、API、云服务和内部资源的操作权限，一旦被攻破，攻击者无需突破多个系统——只需控制这一个已授权的服务即可横向移动。

Moltbook平台数据不可删除：OX Security研究发现专为AI Agent设计的Reddit式论坛Moltbook存在严重隐私缺陷——用户创建的AI Agent账户一旦注册，无法删除。这意味着企业和个人数据可能永久滞留。

#RCE漏洞 #暴露实例 #Moltbook #数据隐私 #安全加固

🔧 v2026.1.29关键安全更新：auth:none永久移除

OpenClaw v2026.1.29引入历史性安全变更：永久移除不安全的 auth: none 配置模式。此前大量用户跟随YouTube教程在VPS上部署时未启用认证，导致网关端口对公网完全开放，任何人可控制实例、读取对话历史、以用户身份发送消息。

升级路径：auth: token（安全令牌）或 auth: password（密码认证），或继续使用Tailscale Serve身份验证。npm包从 moltbot 迁移至 openclaw，扩展作用域从 @moltbot/* 迁移至 @openclaw/*。
